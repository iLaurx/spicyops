# Modo oscuro · 24/10/2026

Ampliación solicitada después del rediseño claro de `DESING.md`. Se conserva su composición, las tipografías locales, los dibujos isométricos, la navegación y las jerarquías. La nueva interpretación utiliza superficies mate azul pizarra, texto crema, contornos gris azulado y acentos turquesa. Las acciones principales usan crema con tinta navy. Los estados conservan colores semánticos y texto.

El botón **Oscuro / Claro** de la barra superior permite alternar la apariencia. El modo inicial es oscuro. La preferencia se guarda localmente y también en una cookie de apariencia sin datos privados, para conservarla cuando cambia el puerto del servidor local al reiniciar. El script de apariencia se carga antes de la hoja de estilos. Si el almacenamiento local está bloqueado, el selector sigue funcionando. No se cambian credenciales, perfiles, cálculos, programación ni operaciones de red.

Se adaptaron las superficies compartidas de todas las pantallas, los campos y controles nativos, modales, confirmaciones, diagnóstico, inventario, respaldos, recuperación y acceso bloqueado. El esquema de equipos tiene una variante SVG oscura propia. El cambio de tema no sustituye el contenido ni recarga formularios.
